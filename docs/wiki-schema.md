# MacClick Wiki Schema

## Where Content Lives

- Keep the catalog in [index.md](index.md) and append dated activity to [log.md](log.md).
- Keep curated originals in `raw/` when a local capture is needed. Create the directory on first use and preserve captured versions. Link directly to existing project files when they are the source.
- Put source summaries in `sources/` and synthesis in `topics/`. Create each directory when its first page is needed. Use lowercase, hyphenated filenames and relative Markdown links for local pages.
- Keep confirmed mistakes and prevention steps in [Errors.md](Errors.md).

## Ingest and Maintain

1. Read the source and check the index for an existing page. Record the origin, version or date when known, and limits on what was reviewed.
2. Summarize the evidence and update any related topic pages. Link claims to the original file, revision, section, or other precise locator. Label inferences and open questions. Attribute conflicting evidence and date it when possible.
3. Update the index, append a dated log entry with the source and affected pages, and verify the links. Preserve earlier evidence when adding corrections.

For wiki questions, read the index and follow citations to the source when details matter. Save durable answers when requested and log those updates.
